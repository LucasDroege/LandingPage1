# React JS Landing Page Template

Este proyecto está basado en una plantilla desarrollada originalmente por **Issaaf Kattan**.

Las modificaciones que realicé consistieron principalmente en traducir al español los textos que originalmente estaban en inglés y adaptar la sección de contacto para que los usuarios puedan comunicarse por WhatsApp.

## Instalación y ejecución

Para ejecutar el proyecto localmente, seguí estos pasos:

1. Cloná el repositorio o descargá el código fuente.
2. Abrí una terminal en la carpeta del proyecto.
3. Instalá las dependencias con el siguiente comando:

   ```bash
   npm install
   ```

4. Iniciá la aplicación:

   ```bash
   npm start
   ```

5. Abrí en el navegador la dirección en http://localhost:3000

**Nota:** si `npm start` no funciona, revisá los scripts disponibles en `package.json`. Dependiendo de la configuración del proyecto, el comando de inicio podría ser `npm run dev`.
